Frequently Asked Questions

Will there be a free plan?

Yes. Shotimer includes a full Free plan supporting up to 3 rooms, 3 timers per room, all core timing modes (countdown, count-up, wall clock), auto-advance linking, and unlimited connected viewers.

Can I use Shotimer offline on venue Wi-Fi?

Yes. Shotimer includes an offline local broadcast server mode that runs on any venue laptop and pairs with phones and tablets over local Wi-Fi with zero external internet required.

Does it require software installation?

No installation is required. Shotimer runs directly in Google Chrome, Microsoft Edge, Safari, and Firefox across Windows, macOS, Linux, iPadOS, and Android.
