Hardware-Level Precision

Unthrottled Web Worker. Zero background tab drift.

Browsers aggressively throttle background tabs, causing ordinary JavaScript timers to lose 10–30 seconds when an operator switches to checking email or notes. Shotimer runs its timing clock inside an isolated Web Worker using performance.now() epoch deltas.

  • Ticking every 50ms: High-precision refresh rate ensures zero stutter on smooth countdown bars.
  • Procedural Web Audio API: Zero external mp3 downloads. Pure mathematical oscillators synthesize soft bell, marimba, and warning beeps directly.
  • Real-Time Cloud Synchronization: Connect unlimited stage monitors, laptops, and crew phones across any internet connection with sub-millisecond responsiveness.
